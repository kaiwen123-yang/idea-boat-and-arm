# 资产来源与参数

初始化尚未下载或导入机器人/相机/船体资产。正式 P1 的首项工作是建立版本化资产清单。

候选官方入口：[agilexrobotics/agx_arm_urdf](https://github.com/agilexrobotics/agx_arm_urdf)。README 分列 Piper、Piper H 与对应夹爪模型；选择具体变体后记录 commit、入口文件、展开工具、许可与校验和。不同版本/变体不能仅改名称当作同一硬件。

每个资产记录：

- 来源 URL、固定提交、文件、作者许可和修改；
- 质量、惯量、重心、关节/执行器限位和夹爪开口；
- 碰撞与视觉几何的差异及缩放；
- 固定关节合并与惯量保留方式；
- 船体/腕部/相机安装变换及 measured / nominal 标记；
- 转换后的 MuJoCo 文件与质量、运动学、碰撞检查结果。

不要把官方 URDF 中的 world 固定连接保留为船体对地固定。机械臂应接到自由船体的基座，官方夹爪照真实行程驱动，腕部相机安装体只计重一次。

尚无可核验的 DC1 K/D、手眼标定、相机间外参或附件质量惯量；使用临时值必须说明。详见 [CAMERA_SPEC](../docs/CAMERA_SPEC.md)。

第三方许可按原来源保留；本次不为用户自动选择整个项目的开源许可证。大型可重取的网格放 downloads/ 或使用明确的下载/转换脚本，必要的小型资产和出处可纳入版本管理。
