# 研究范围与待验证假设

最后整理：2026-11-18。依据：本项目对话中已确定的研究问题、用户在同日补充的正式约束与已核查的一手文献。当前为仓库初始化，尚未在本仓库搭建或运行仿真。

## 1. 项目目标

研究自由浮动无人船与机械臂对漂浮物的动态接触控制，以小型刚性浮冰的选择性移除为代表应用。完整任务包括目标确认、接近、相对跟踪、接触、夹持或推移、转移、释放、结果验证，以及失败后的继续操作。

核心问题是：**在未知共同外扰、观测滞后、不可撤销的执行前缀和接触模式切换下，如何学习新动作真正能够改变的后果，并利用这些信息可靠地改进反馈控制策略？**

目标期刊可以按 T-RO 的研究深度规划，但投稿层级不是已完成事实，也不构成性能承诺。项目不以“首次组合无人船、机械臂、VLA 和世界模型”作为当前创新结论。

本项目的科学问题、创新判断和实验结论不依赖无关个人记忆。用户于 2026-11-18 明确授权只读检索 π 系列算法项目与腿臂协同控制项目中的硬件事实；本项目仅使用这些已授权且与当前装配有关的事实，不据此继承其他项目的算法效果、环境或实验结论。硬件信息的证据级别统一为“授权对话检索记录，未独立复核原始采集文件”；仓库不发布原始聊天或个人信息。

### 用户已确定的实施约束

- **效果优先，允许充分探索。** 完全随机动作干预是正式实验路径和对照，不预设它浪费预算，也不预设主动采样或节约计算的方法更好。根据实际表现决定后续方法。
- **最终版本采用粒子流体。** 初期使用刚体与经过基础验证的等效载荷；最终研究同时解决波浪生成、双向流固耦合收敛、大规模并行和机器人学习。P1 后即可并行启动 [粒子流体支线](FINAL_FLUID_TRACK.md)，不等待视觉学习完成。
- **机械臂暂定 Piper 家族。** 授权记录中的 Piper H 与官方夹爪作为参考配置，具体型号和资产版本仍需固定。正式 P1 先对齐模型资产、质量/惯量、关节与执行器限位、夹爪和安装变换，再验证船臂物理。不能将旧通用机械臂参数当成 Piper 的硬件规格。
- **加入单腕部相机。** 授权记录中的 Orbbec DaBai DC1 作为相机配置参考。P1 就完成挂载、基本成像、时间戳与坐标核对（P1-08），视觉策略学习放在 P5；标定、真实安装变换和称重/惯量核对尚未完成。单腕部视角的遮挡、视野丢失和目标重识别需要明确处理，不以未选择的外部相机补足可观测性。详见 [CAMERA_SPEC.md](CAMERA_SPEC.md)。

原设计中的机械臂 12 kg、臂展 0.75 m、夹爪开口 0.14 m 与平台总质量 72.15 kg 均仅属于 `reference_proxy`，不代表 Piper 或实际装配。P1 必须使用经审计的资产与装配质量重新核对浮力、惯量和可达性；配置以本项目明确选择为准。

实验应如实记录计算与采样开销，并设置必要的等预算归因对照；这些记录不作为提前限制主实验探索的理由。

## 2. 系统中的职责

| 部分 | 作用 | 应保持的边界 |
|---|---|---|
| 语言与视觉任务接口 | 解释目标、约束、任务阶段，后续输出技能或参考动作 | 仅解析指令时，准确称为语言条件任务接口；不能直接宣称完整 VLA 能力 |
| 目标状态 | 维护物体身份、目标区域和指令语义 | “刚才指定的物体”与“每次选择最近物体”具有不同更新规则 |
| 状态与外扰估计 | 使用带时间戳的观测、执行记录和历史推断联合状态 | 对不可观测量保留不确定性；有限历史不自动构成完整 Markov 状态 |
| 动作条件世界模型 | 预测船、臂、目标及接触随实际动作的演化 | 首先采用结构化状态模型；它不会自动生成未来相机图像 |
| 快速反馈策略 | 控制推进器、机械臂和夹爪 | 受到真实执行器布置、限幅和关节约束限制 |
| 事件评估与恢复 | 在接触、滑脱或身份丢失时评估下一动作 | 在同一任务中继续操作，不能用环境重置代替恢复 |

语言任务状态维持语义，世界模型提供物理后果预测。两者需要协作，但世界模型不会自行保证目标身份正确。

## 3. 学习路线

借鉴 [SuperMimic](REFERENCES.md#r1-supermimic) 的训练范式：从普通物理仿真器采集轨迹，学习可微动力学，通过短时模型展开优化策略，再回到物理仿真器验证并补充数据。

- 梯度来自学习模型，物理仿真器本身不必可微。
- 这种策略优化不是简单的教师策略蒸馏。
- 初期以结构化状态估计和目标条件反馈策略研究机制；视觉与 VLA 的适配另行验证。
- 世界模型主要用于训练；是否保留事件触发的在线预测，需要做收益与开销对照。
- 想象展开长度按物理时间、动作实际生效时刻和任务需求选择，不能直接照搬其他论文的步数。
- 真实参数或未来波浪真值可以用于训练监督、诊断或上界实验；主要方法的输入必须符合预定部署观测条件。

需要分别研究高层 VLA 输出迟到和底层感知、控制、通信、执行迟到。如果快速底层策略降低了大型模型调用频率，应单独归因这种架构收益。

## 4. 已有工作与候选扩展

以下边界会影响算法设计，不应因任务换成船臂就忽略。

| 已有基础 | 当前可依赖的结论 | 本项目仍需证明的内容 |
|---|---|---|
| SuperMimic | 学习可微动力学并通过模型梯度训练反馈策略已有方法与实机示例 | 未知海洋外扰、操纵外物和执行延迟下是否有效 |
| [DDPPO](REFERENCES.md#r2-ddppo) | 经验样本有限差分、方向导数监督和预测模型/梯度模型分工已有先例 | 隐藏共同外扰和动作前缀下，主动配对干预是否比近邻差分更有效 |
| [MB-MIX](REFERENCES.md#r3-mb-mix) | 动力学 Jacobian 监督与不同展开长度混合已有先例 | 无解析动力学导数时，怎样通过充分探索获得可靠、可验证的控制响应监督 |
| [Suh et al.](REFERENCES.md#r4-gradient-estimators) | 不连续与刚性会影响一阶估计；一阶和零阶估计结合已有研究 | 学习模型误差、未知外扰和延迟共同存在时的可靠性判据 |
| [RTC](REFERENCES.md#r5-rtc) | 异步动作块执行与保留已提交前缀已有研究 | 联合物理预测、接触决策和新动作作用归因的收益 |
| [Confidence-Aware Object Capture](REFERENCES.md#r6-confidence-aware-capture) | 已有浮动基座扰动与置信信息下的目标捕获研究 | 只有摘要及作者资料证据；不得据此断言其正文缺少某个机制 |
| [AUTO-IceNav](REFERENCES.md#r7-auto-icenav) | 船—冰接触相关规划与物理试验已有系统工作 | 船臂操作、抓取及共同外扰下的方法需要单独验证 |

候选研究机制是：固定同一物理检查点、相同外源波浪实现与不可修改动作前缀，只干预新动作，学习其有限时域后果，并用独立物理分支检验模型建议的方向是否有效。首先允许充分的随机干预覆盖；主动或任务相关方向选择是根据表现决定的候选扩展。

这是一项**待验证扩展**。有限差分、共同随机数、队列增广或梯度混合各自都不能直接作为原创贡献。必须解释干预选择、执行归因或可靠性机制解决了什么具体问题，并与相近方法公平比较。

固定外源波浪不等于固定净水动力：新动作改变姿态、浸没和相对流速后，每个分支必须重新计算载荷。跨接触模式的有限幅度差分也不能自动称为真实局部导数。开环动作段响应与闭环策略更新效果需要分别定义、分别检验。

## 5. 三个可证伪假设

| 假设 | 要检查的证据 | 会削弱或否定该假设的结果 |
|---|---|---|
| H1：联合历史与扰动建模有价值 | 实际生效时刻的相对位姿、速度、接触事件和候选排序改善 | 只在输入真实波浪参数时改善；或预测改善无法转为控制收益 |
| H2：有效模型梯度有额外价值 | 充分探索下的最终任务表现，以及等数据/等计算对照中的真实改进 | 梯度建议在物理环境中无效；收益只来自额外数据或更强状态输入，却被错误归因为梯度机制 |
| H3：收益延伸到完整任务 | 正确目标清理、区域保持、恢复成功率及约束表现改善 | 只改善局部跟踪；错误目标率或完整任务失败没有改善 |

优先分析失败机制。若强物理基线已经足够，或者模型梯度没有增益，应据实调整研究问题，不通过削弱基线或只展示成功案例维持预设结论。

## 6. 任务与评价边界

首篇工作先限定为具有浮力的刚性物体接触与转移。冰破裂、融化、甲板上浪、复杂尾流、多浮体通过水体的完整相互作用，都不由当前阶段一低阶模型自动覆盖。

完整任务成功应同时考虑：正确物体身份、移出指定区域、约定保持时间，以及任务约束。接触成功、提起成功与清理成功分别记录。恢复必须在同一任务内评价。

后续主要指标包括：

- 完整任务成功率、错误目标率、任务时间与约束违反；
- 滑脱、恢复成功率和恢复耗时；
- 生效时刻的相对状态误差、候选排序与方向改善比例；
- 完整闭环策略更新后的真实回报变化；
- 观测年龄、延迟分布、在线计算开销、训练时间和总物理仿真步数。

训练与测试按整个波浪实现、物体或任务组合划分，不能将同一轨迹随机拆帧作为主要泛化证据。模型分支样本计入训练成本。主要方法使用相同观测、执行权限和评价场景，特权信息上界单独报告。最终效果评估允许各方法充分探索；另外设置数据量和计算预算受控的归因实验，解释改进来自什么。不能用短预算下的输赢代替用户要求的充分效果验证。

## 7. 证据层级

1. **实现正确性**：正确实现所选模型和接口。
2. **数值可靠性**：主要现象不由步长、求解器或状态重置错误决定。
3. **模型现实有效性**：通过实测或独立可信模型核验物理近似。
4. **算法有效性**：与强基线及消融比较，支持明确方法结论。
5. **完整系统能力**：通过实际观测、语义目标和恢复完成完整任务。

阶段一主要交付前两层证据。粒子流体在 F 支线发展、P6 与算法合流；P7 补充水槽、真实浮体/冰材料和独立物理证据。粒子数更多不自动代表结果更真实，仍要验证波浪、耦合、收敛和物理响应。同一套水动力公式接入两个软件框架，不等于完成两套独立物理模型的验证。粒子压力或动量交换已经产生的载荷，不得再与等效浮力/阻力重复施加。
