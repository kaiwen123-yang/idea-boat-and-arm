# 最终粒子流体路线：正式目标与验收顺序

最终系统必须包含粒子流体，并在其中处理波浪生成、双向流固耦合收敛、大规模并行和机器人学习。这是用户确定的研究目标。初期等效海洋载荷用于尽快建立算法与诊断基础，不能作为最终流体目标的替代品。

P1 通过后可以启动 F 支线，与 P2–P5 的控制、世界模型和视觉语言研究并行；P6 合流。并行不等于把多个未验证问题同时写进同一个学习环境，应该保存可隔离的基础试验。

## 阶段与推进依据

| 阶段 | 核心问题 | 产物和推进依据 |
|---|---|---|
| F0 求解器与接口 | 哪个实现能处理所需粒子流体、边界与刚体反馈？ | 固定版本、许可、力/冲量接口、粒子状态、重启接口；用最小案例核对真实能力 |
| F1 波浪水槽 | 波场是否按要求生成并可测量？ | 静水、规则波、反射/吸收、质量漂移；多个测点的振幅、相位、频率/波谱与分辨率比较 |
| F2 双向耦合 | 水推动船，船/臂/目标运动也改变水吗？ | 自由漂浮、自由衰减、刚体运动、接触提放；力/冲量平衡、作用反作用、耦合步长敏感性 |
| F3 数值收敛 | 结果是否随着空间/时间/耦合分辨率稳定？ | 粒子间距、时间步、迭代/耦合子步的系统比较；误差与成本同时报告 |
| F4 并行环境 | 大批不同海况与动作的环境是否独立、正确且有吞吐？ | 多环境隔离、复位/保存恢复、显存与吞吐、相机开销、学习数据一致性 |
| F5 机器人学习 | 策略能否在粒子域训练/微调/评估并保持机制优势？ | 固定最终评测任务、强基线、失效分析、低阶到粒子域偏差与迁移实验 |

验收阈值应在实验前结合应用尺度与基准精度定义，不伪造一个通用“5% 就算海洋正确”的标准。每阶段可以暴露求解器不适用；届时根据证据更换实现，而不是删去最终目标。

## 1. 求解器选择不预先等同于物理答案

可评估 SPH、MPM 或合适的粒子液体实现。它们是候选技术路线，不是已经选定的具体最终引擎。初步官方资料包括：

- [Isaac Lab v3.0 MPM](https://isaac-sim.github.io/IsaacLab/v3.0.0/source/concepts/using_mpm.html)；
- [Isaac Lab coupled solvers](https://isaac-sim.github.io/IsaacLab/v3.0.0/source/concepts/coupled_solvers.html)；
- [PhysX particles](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/110.1/dev_guide/particles/particles.html)。

这些资料说明可用接口和限制，不能代替本项目收敛与海洋验证。实施时重新核对所装版本；某条粒子碰撞路径可能只把刚体当作给定边界，必须实际证明反向冲量进入自由刚体求解，而非凭视觉宣布双向耦合。

学习可微世界模型不要求最终物理求解器可微。后端优先由物理有效性、状态可重复性、数据接口和真实吞吐决定；可微能力是可评估属性。

## 2. 波浪生成与测量

先在无船水槽中建立已知水深、边界条件与测点。规则波检查目标周期、幅值、空间相位和色散一致性；随后再考虑随机波谱。记录造波方式、吸收区、有限水槽反射、自由表面提取方法、质量/体积漂移和瞬态窗口。

船体进入后，分开记录入射、反射/绕射及局部表面运动。不能把从静水粒子中叠加视觉正弦水面当作已生成物理波浪。训练随机海况应有明确分布与留出条件。

## 3. 双向流固耦合与唯一载荷来源

水对船/目标/入水夹爪施加力或冲量；刚体速度和姿态也改变液体。需记录每个耦合区间的边界状态、交换冲量、更新顺序与收敛残差，并对耦合子步/迭代做对照。

粒子已经计算的浮力、压力或阻力不能再完整叠加初期等效模型。若采用混合项，明确分解来源和未解析部分。重力、关节反作用、接触同样不能重复添加。

先做单浮体静水/自由衰减和受迫运动，再加入自由船体上的活动机械臂，最后加入目标接触与提放。不能用固定船体、预设目标轨迹代替自由系统的双向验证。冰在这一阶段仍可先是刚体；破碎、融化等新主张需另增模型和证据。

## 4. 收敛覆盖三个层面

- 空间离散：粒子间距、核/网格分辨率、边界表示。
- 时间离散：液体步长、刚体步长、控制和传感器周期。
- 耦合求解：交换频率、迭代数/残差、显式或隐式处理方式。

采用多个分辨率比较吃水、恢复/衰减、波幅相位、轨迹与交换冲量。强接触与自由表面事件可使用统计/积分量辅助，不能声称所有瞬时轨迹必然逐点相同。更细不自动更正确；需检查稳定区间、质量漂移及异常能量。

同一底层求解器包装成另一个框架不能算独立物理验证。参考解析解、可信实验数据和独立模型时说明各自适用条件及误差来源。

## 5. 并行与学习共同设计

记录在实际粒子数、刚体数、相机数量、波况及接触负载下的每秒物理步/环境步、峰值显存、复位和采样成本。区分单环境延迟和批量吞吐，排除只统计空场景的速度结论。

多环境隔离要检查水粒子、碰撞、光照/相机、随机种子和复位状态。环境扩容后重新检查物理与传感器正确性，不只确认程序没有崩溃。

学习路线可从等效载荷训练、粒子域评估与适应开始，随后开展粒子域数据收集和直接训练/微调。最终论文的粒子域有效性主张必须由粒子环境中的实际结果支持，不能只展示离线回放。

用户允许充足预算，因此保留充分随机动作与大规模试验。并行优化关注能否支撑目标实验和复现，而不是为省预算提前牺牲物理验证或必要覆盖。

## 6. P6 合流条件

合流前完成：共同动作与观测时间契约、经过检查的船臂资产、原生腕部相机接口、流固载荷唯一性、基础收敛、复位/保存恢复、至少一组粒子域控制基线。

合流后才评价世界模型在不同物理保真度下的预测/动作敏感度、策略改进、目标一致性、择时与恢复。流体平台贡献与学习方法贡献分别归因；系统工作量大本身不能代替方法创新证据。
